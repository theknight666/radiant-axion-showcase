# Axionis Growth Agency — Official Showcase

A premier, high-performance web experience built for **Axionis Growth Agency** — an India-based senior-led growth and conversion architecture firm operating globally.

---

## 🌟 Key Features

- **Apple-Grade Liquid Glass Preloader:** Full-screen liquid glass overlay with 14 physics-accurate lighting layers (specular hairlines, edge shadows, caustic pulse, chromatic blue fringe, noise grain) refracting the live site behind it.
- **3D Floating Design System:** Super-curved geometry (`rounded-[36px]`, pill badges) with multi-layered ambient depth shadows and tactile top specular highlights.
- **Complete Route Architecture:**
  - `/projects`: Video case study showcase with interactive category filter bar and modal deep-dives.
  - `/agency`: Agency manifesto, operating principles, and India headquarters (Bengaluru & Mumbai) with live IST clocks.
  - `/services`: Capability matrices and the interactive 12-month Growth ROI slider calculator.
  - `/journal`: Editorial field notes, executive takeaway drawers, and newsletter subscription.
  - `/connect`: Interactive strategy call scheduler and confidential RFP submission.
  - `/careers`: Culture perks, senior squad openings, and job application modal.
  - `/press`: Official press releases, downloadable vector logos, and brand guidelines.
  - `/privacy` & `/terms`: Legal terms compliant with Indian data governance & DPDP Act 2023.
- **Global Interactive Modals:** 3-step booking calendar, case study reader, and job application forms.

---

## 🛠️ Technology Stack

- **Framework:** React 19 + TypeScript + Vite
- **Routing:** TanStack Router (`@tanstack/react-router`, `@tanstack/react-start`)
- **Styling:** Tailwind CSS v4 + custom 3D floating & liquid-glass utilities
- **Icons & Effects:** `lucide-react`, `sonner`, `shaders`
- **Typography:** Bebas Neue, Inter

---

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm or bun

### Local Development

```bash
# 1. Install dependencies
npm install

# 2. Start the local dev server
npm run dev

# 3. Open in browser
http://localhost:8080/
```

### Production Build

```bash
npm run build
npm run preview
```
